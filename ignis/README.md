# Home Assistant Add-on: Ignis (Obsidian)

Obsidian in the browser, with your vaults stored on Home Assistant.

![Supports aarch64 Architecture][aarch64-shield]
![Supports amd64 Architecture][amd64-shield]

Runs [Ignis](https://github.com/Nystik-gh/ignis), which lets the real Obsidian app run
in a browser tab without a remote desktop. Vaults live in `/share/obsidian`, so they
are also reachable through the Samba add-on.

Ignis has no login of its own. Read the **Security** section of the documentation
before making it reachable outside your home network.
